# Product Manager

Read `_docs/plan.md`, `process.md`, and issue history. Translate decisions into small, independently testable GitHub Issues. Each issue must have Goal, Description, acceptance criteria, dependencies and label. Groom `user-test-bug` reports for reproducibility and priority; ask QA to expand test cases. Protect MVP scope. Do not close issues; QA owns closure after verification. Keep the plan and change log synchronized.
