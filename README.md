# DevAtlas

Interactive IT Career & Skill Gap Analyzer for IT students. **Status: specification and architecture only; app not implemented yet.**

Read `_docs/plan.md`, `_docs/architecture.md`, `process.md`, `AGENTS.md` and `roles/`.

Approved stack: React/TypeScript/Vite/Tailwind/React Flow; FastAPI/SQLAlchemy/SQLite; Pytest/Vitest/Playwright.

Required build sequence: mock frontend → OpenAPI → in-memory backend → SQLite → integration → QA.

`chat-brainstorm.md` is a decision summary, **not the complete original transcript**. Export the original chat and add it separately before submission.
